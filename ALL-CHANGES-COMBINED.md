# Charleston Donuts — Combined Menu & Order Ahead Update

This package combines the full sequence of uncommitted updates into one repository-ready set of files.

Included:

- Updated menu items and prices from the provided hierarchy workbook.
- Required modifier hierarchy for configurable menu items.
- `None` flavor option for Cappuccino, Iced Coffee, Milkshake, and other applicable flavor selections.
- Dozen, Eight Pack, and Half Dozen quantity-style flavor builders.
- Live selected-count tally for fixed-size donut boxes.
- Add to Order button enabled only after the exact required count is selected.
- Grouped Individual Donuts dropdown with per-variety minus/plus controls.
- Live individual-donut quantity and running-price tally.
- Individual donut varieties itemized separately in the Order Ahead cart and submitted order summary.
- Donut Holes package selection and flavor/assortment selection.
- Drink pricing determined by selected size for Hot Coffee, Cappuccino, Hot Chocolate, Iced Coffee, and Milkshake.
- Existing Formspree order submission, pickup scheduling, tax calculation, and customer confirmation workflow retained.

This package contains the production CNAME file for charleston-donuts.com. Copy the contents into the primary repository, test locally, and commit once approved.
