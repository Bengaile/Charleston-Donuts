# Persistent Header Cart — Targeted Update

This package adds only the approved cart navigation behavior:

- Keeps automatic cart opening after an item is added.
- Keeps Continue Shopping.
- Adds a persistent cart icon and count badge on every customer-facing page.
- On Menu, the icon opens the existing cart drawer.
- On Order Ahead, the icon moves the customer to the existing cart/checkout section.
- On other pages, the icon opens Menu with the existing cart drawer automatically displayed.

No menu data, pricing, hierarchy, photos, Formspree configuration, pickup scheduling,
navigation destinations, or other page content was changed.

Files intentionally changed:
- 13 customer-facing HTML files
- assets/css/header-cart.css (new)
- assets/js/header-cart.js (new)

Owner portal was intentionally not changed.
